# zeny: приложение плеера (Android 4.2, Innioasis Y1)

Основа: InniClassic 1.4.5 (FabianZettl), он в свою очередь построен на JJ Launcher (ismileblue).
Здесь это локальный форк: `applicationId` и пакеты оставлены `com.themoon.y1`, чтобы не терять данные и
права системного приложения. Оригинальные README и список изменений лежат рядом:
`UPSTREAM_README.md`, `UPSTREAM_CHANGELOG.md`. Лицензия: `LICENSE` (некоммерческая), подробности в
[../NOTICE.md](../NOTICE.md).

## Что добавлено относительно InniClassic

- Тема **Zeny** (по умолчанию): палитра, шрифты Onest и Unbounded, радиус 26, плоские капсулы вместо
  iPod-стекла; справа в главном меню: карточки-слэбы с роботами (генерируются `scripts/make-slabs.py`).
- Русский перевод (около 455 ключей), настройки разбиты на 6 разделов.
- Экран USB, экран блокировки (снятие удержанием центра, тремя нажатиями или любым способом), экран
  веб-сервера с роботами, скруглённые обложки, плашка уведомлений, оверлей сканирования с роботом.
- Карточки «мало заряда» и «не та зарядка» вместо заводских диалогов (вместе с патчем SystemUI).
- Иконка батареи и громкости, нарисованные кодом; сердце избранного.
- Один таймер «Автоблокировка» вместо двух; системный тайм-аут экрана подстраивается под него сам.
- Звуковой тракт Zeny Audio Engine: Opus в float, ресемплер sinc, профиль Zeny Natural, Sound Check по R128,
  нативное ядро DSP (`app/src/main/cpp`), см. [../docs/AUDIO.md](../docs/AUDIO.md).
- Викторина играет opus/flac; «Исполнители» делятся по отдельным артистам (несколько тегов `ARTIST`).
- Инкрементальный скан библиотеки: после заливки музыки разбираются только новые файлы.
- Включение Wi-Fi по кнопке веб-сервера.
- Поддержка m3u8-плейлистов с `#EXTINF`-названиями вида «Исполнитель - Название».
- Строка «Обновление системы» убрана: она тянула бы чужой InniClassic поверх нашего форка.

## Сборка

JDK 17 (Gradle 8.7, AGP 8.6), Android SDK (platform 35, build-tools 35) и NDK 28 для `libzenydsp.so`:

```sh
echo "sdk.dir=$ANDROID_HOME" > local.properties     # не коммитится
../scripts/build-y1.sh                              # NDK-сборка + armeabi-v7a → ../out/zeny-y1.apk
../scripts/build-emu.sh                             # arm64 для эмулятора (AVD 480x360)
```

Версия: `versionName` в `app/build.gradle`, `versionCode` = дата сборки (`-Py1.vc=MMDDHHMM`), поэтому тема
перепаковывается при каждой новой сборке.

Установка на плеер: только `../scripts/deploy-system.sh` (системное приложение + JNI-библиотеки в
`/system/lib`, см. [../docs/SYSTEM.md](../docs/SYSTEM.md)).
