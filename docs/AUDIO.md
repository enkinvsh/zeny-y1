# Аудиодвижок zeny (Zeny Audio Engine)

Весь звуковой тракт плеера: декодер Opus, DSP, вывод. Реализация: `android/app/src/main/java/com/themoon/y1/managers/ZenyAudioProcessor.java` (эталон на Java) и `android/app/src/main/cpp/zenydsp.c` (то же самое на C).

## Что было не так в стоковом тракте

Снято с устройства (`dumpsys media.audio_flinger`, `dumpsys media.audio_policy`) и из кода приложения:

1. Выход AudioFlinger на Y1 умеет только 44100 Гц, а Opus декодируется в 48000 Гц. Android 4.2 переводил частоту целочисленным линейным ресемплером 160:147.
2. Приложение безусловно включало эффекты MediaTek (Equalizer, BassBoost, Virtualizer) даже со значениями «выкл»: поток шёл через 16-битный EffectChain.
3. Выравнивание громкости (Sound Check) на Android 4.2 не работало: код проверял `SDK_INT >= 19` (LoudnessEnhancer), на Y1 `SDK_INT = 17`. Декодер libopus отдавал 16 бит и срезал межсемпловые пики выше 0 dBFS внутри себя.
4. Программные процессоры `Y1EqAudioProcessor` и `Y1CrossfeedAudioProcessor` конвертировали short↔float на каждой стадии с жёстким клиппингом, без запаса по уровню и без дизеринга.

## Конвейер

Декодер libopus переведён в float (`opus_decode_float`), дальше всё считается в 32-битном float, и только на выходе квантуется в 16 бит.

| Стадия | Что делает |
|---|---|
| Входное усиление | Запас -1.2 дБ под межсемпловые пики. Sound Check: точное усиление из тега `R128_TRACK_GAIN` / `REPLAYGAIN_TRACK_GAIN` (диапазон -9.5…+4 дБ), для файлов без тега медленный гейтированный нормализатор (постоянные времени 3 с вверх, 6 с вниз). |
| 10-полосный EQ | Биквады DF2T, считаются только полосы с усилением от 0.05 дБ. |
| Zeny Natural (по умолчанию включён) | Гармоника суббаса ниже 95 Гц, тёплая полка 62 Гц (+1.5 дБ), снятие цифровой колкости 3.85 кГц (-1.5 дБ) и 6.2 кГц (-0.8 дБ), «воздух» от 13.5 кГц (+1.7 дБ). Середина (1-2 кГц) по уровню не меняется, чтобы включение профиля сравнивало тембр, а не громкость. |
| Crossfeed Бауэра | 8.5% внутри Zeny Natural либо 15/24/33% по настройке; ФНЧ 700 Гц, межуншная задержка 250 мкс. |
| Ресемплер 48 → 44.1 кГц | Полифазный оконный sinc (окно Кайзера, beta 6, 48 отводов, 147 фаз). Плоско до 19 кГц, -0.5 дБ на 20 кГц, подавление зеркала выше 23 кГц 52-68 дБ. Для нестандартных частот запасной кубический Эрмит. |
| Выход | Мягкое насыщение выше -1.7 dBFS (монотонное, колено C1) и треугольный дизеринг TPDF перед округлением до 16 бит. |

Меню: Настройки → Звук → «Zeny Natural». Миграция настроек при первом запуске новой версии сбрасывает старый пресет эквалайзера и включает Zeny Natural и Sound Check.

## Нативное ядро

Тот же цикл на Java на Dalvik (Cortex-A7 1 ГГц, JIT нет) занимал до 70% одного ядра при воспроизведении, процессор держал полную частоту весь трек. Поэтому горячий цикл вынесен в `libzenydsp.so`.

Ограничения, которые определяют устройство файла:

* Плеер на Android 4.2 (API 17), а NDK собирает под API 21+. Поэтому в `zenydsp.c` нет ни одного вызова libc/libm (даже `memset`, целочисленного деления и `sqrtf`); `scripts/build-native.sh` падает, если `nm -u` показывает хоть один внешний символ.
* Java остаётся эталоном и запасным путём: если `.so` не загрузилась (эмулятор на другой архитектуре, файл не лёг в `/system/lib`), `ZenyAudioProcessor` считает на Java.
* Библиотека кладётся в `/system/lib` вместе с остальными JNI-библиотеками (`scripts/deploy-system.sh` делает это для всех `lib/armeabi-v7a/*.so` из APK).

Замер на реальном Y1 (`tools/dsp-test/run.sh device`, 10 с стерео 48 кГц, доля одного ядра):

| Режим | Java | Нативное |
|---|---|---|
| 44.1 кГц без ресемплера, Natural выкл | 18.5% | 1.0% |
| 48 кГц sinc, Natural выкл | 32.8% | 3.3% |
| 48 кГц sinc + Natural | 39-50% | 5.3% |
| + AGC | 52% | 5.7% |
| + EQ 10 полос | 68% | 9.1% |

При реальном воспроизведении поток `ExoPlayer:Playback` в `top -t` показывает 5% против 30% на Java-сборке, суммарная загрузка системы около 11% против около 37%. Выигрыш по времени работы от батареи не измерялся.

## Теги громкости

Приложение читает тег `R128_TRACK_GAIN` (Q7.8 относительно -23 LUFS) или `REPLAYGAIN_TRACK_GAIN`. Первый можно записать без перекодирования: громкость измеряется по EBU R128 (`ffmpeg` с фильтром `ebur128`), результат пишется в Vorbis-комментарий Ogg Opus.

## Проверка

`tools/dsp-test/run.sh` собирает нативное ядро для Mac и гоняет настоящий класс на JVM:

* `Harness`: 11 групп (АЧХ ресемплера, клиппер, жёсткие входы, независимость от размера чанка, АЧХ Zeny Natural, Sound Check, AGC, форматы 8/16/24/32/float, моно, flush при перемотке, другие входные частоты), запускается для Java и для нативного ядра.
* `Parity`: 19 конфигураций, нативное ядро против Java на одном входе. Расхождение не больше 1 младшего бита. Тот же `Parity` прогнан и на самом Y1 (ARM-сборка против Java на Dalvik): результат совпал.

## Что не проверено

* Слуховая оценка: профиль Zeny Natural настроен по измерениям и литературе, не на слух в режиме слепого сравнения.
* Реальный выигрыш по батарее.
* Эффекты MediaTek по-прежнему создаются приложением (в выключенном состоянии, `State 000`), цепочка AudioFlinger для сессии существует, но ничего не обрабатывает.
