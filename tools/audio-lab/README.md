# audio-lab — цифровой измерительный стенд звука Zeny

Прогоняет эталонные сигналы через тот же тракт, что у плеера: Opus 140k → настоящий `ZenyAudioProcessor`
(ядро на Java и нативное `zenydsp`) → 16 бит 44.1 кГц. Затем меряет, что каждая стадия сделала с сигналом.
Код приложения не меняется: стенд компилирует исходники из `android/` как есть.

## Запуск (одна команда)

```bash
tools/audio-lab/run-digital.sh
```

Полный прогон с нуля занимает около 2–3 минут. При первом запуске создаётся venv (`uv`, numpy/scipy/matplotlib).
Итог: exit 0 и строка `готово: …`.

## Что нужно на машине

- JDK и `ANDROID_HOME`, как в `scripts/env.sh` (нужен `platforms/android-34/android.jar`).
- В `~/.gradle` должны лежать jar ExoPlayer 2.13.3 (core, common): один раз собрать приложение через Gradle.
- `cc` для хостовой сборки нативного ядра (`scripts/build-native.sh`).
- `ffmpeg` с `libopus`, `ffprobe`, `uv`.
- Библиотека `~/Music/Y1/Music` для трёх музыкальных отрывков (громкий хип-хоп, рок, соул); исполнители выбираются в `EXCERPTS` в `gen_signals.py`, подставьте свои.

## Файлы

| файл | что делает |
|---|---|
| `run-digital.sh` | вся цепочка: сборка, стимулы, рендер (Java + натив), анализ, копия графиков в `img/` |
| `gen_signals.py` | стимулы 48 кГц float (истина), их Opus-версии и декод, 3 отрывка из библиотеки, `manifest.json` |
| `Render.java` | пакетный рендер через настоящий `ZenyAudioProcessor`; строки задания: `in out air xf sc tagDb` |
| `labutil.py` | общие измерения: выравнивание, Welch H1, полосы 1/3 окт., тоны/THD, свип Фарины |
| `analyze.py` | шум, каналы, Opus, сравнение Java и натива, графики, `--selftest` (тождество = 0 дБ) |
| `tones.py`, `music.py` | синусы/свип/IMD/ресемплер/тишина; софт-клип и разница Air +12/Pure на музыке и запас пиков |
| `REPORT-digital.md` | отчёт с выводами |

Результаты: `work/audio-lab/results/summary.json` (все числа), графики `work/audio-lab/results/plots/*.png`,
копия графиков в `tools/audio-lab/img/`. Промежуточные WAV лежат в `work/audio-lab/{sig,opus,dec,out}` (~1.3 ГБ, gitignored).

Стадии: `T1` — только Opus. `T2` — DSP в прозрачном режиме (Air 0, кроссфид выкл). `T3` — «Воздух» шаг 3 (+12 дБ, кроссфид 0).
Суффикс `L` означает вход без потерь, `C` — вход после Opus. `T2S`/`T3S` — Air 0/Air +12 + Sound Check с тегом трека.
`STAGE1..3` — шаги «Сцены» (бывший кроссфид) без «Воздуха». `AIR1..5` — шаги «Воздуха» (+6/+9/+12/+15/+18 дБ) на коротком наборе стимулов.
